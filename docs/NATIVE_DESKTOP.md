# Windows 原生单步操作

原生操作和“合成模板回放”是两个入口。`StartTemplate` 始终使用文件图片与 dry-run；`StartNative` 绑定真实窗口，并使用服务的全局许可与持久审计。原生适配器只用于 Windows，界面不持有窗口句柄或键鼠执行权限。

## 第一次验收

先保持声音、麦克风和主动说话关闭。双击便携包中的 `AIex-Test-Window.cmd`，由你主动打开专用画布；不要选择学习、聊天或私人内容窗口。开发测试不会替你运行这个入口。

在“设置与诊断”找到“专用窗口操作”，点“扫描可选窗口”，选择测试画布。扫描是显式只读操作，列表有数量与消息大小上限；选择后能看到程序的完整授权路径、进程身份、物理位置及 DPI。

许可默认关闭。关闭工作室，在**当前使用的服务配置**中修改已有的 `[safety]` 段，不要再添加重复段。本地向导使用 `data/native-bootstrap.toml`，原有外部连接使用 `data/ai-ex.local.toml`：

```toml
[safety]
automation_enabled = true
allowed_capabilities = ["screen_read", "mouse_input", "keyboard_input"]
allowed_targets = ['D:\实际解压目录\ai-ex-platform-helper.exe']
audit_path = "data/logs/automation-audit.jsonl"
```

把示例路径替换为扫描显示的**完整、精确路径**。它没有通配符，不因“准备所选窗口”自动授权，也不授予进程启动能力。重新打开程序和测试画布，再扫描选择；进程重启后必须重新绑定，不能沿用旧句柄。

1. 设置较小的截图与动作预算，点“准备所选窗口”。此时是准备状态，不会捕获或发送输入。
2. 选择手动单步，保存一个点击、按键、文字、拖动、滚动、等待或无动作。点击与拖动使用界面显示的**物理桌面坐标**，允许负坐标；输入点必须在已绑定窗口的客户区内。
3. 在运行设置中启用快捷键并应用，核对“已注册”状态。注册冲突会明确报告，不自动更换按键。
4. 切回测试画布，按 `Ctrl+Alt+F9` 核对恢复，再按 `Ctrl+Alt+F11` 执行保存的单步。每步会先获取新画面，然后检查窗口、许可、代次与预算。快捷键松开后再观察结果。
5. 按 `Ctrl+Alt+F8` 暂停，或回工作室点“停止本次操作”。`Ctrl+Alt+F7` 是全局急停；急停后重新启动服务才能重新取得许可。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+Alt+F6 | 打断回复与试听 |
| Ctrl+Alt+F7 | 全局急停并关闭主动说话 |
| Ctrl+Alt+F8 | 暂停原生会话 |
| Ctrl+Alt+F9 | 核对目标并恢复原生会话 |
| Ctrl+Alt+F10 | 切换已确认的悬浮字幕设置 |
| Ctrl+Alt+F11 | 执行已保存的原生单步 |

快捷键默认不注册，每次服务重启后需重新应用。工作室不会主动把别的窗口切到前台；因此不要用工作室按钮模拟“保持目标在前台”的测试。

## 视觉建议

已经配置可用视觉模型时，可选择视觉单步，保存一个清楚的目标，再切回专用画布执行。默认文字模型 Qwen3 4B 不具备这里需要的图像能力；没有视觉模型时使用手动单步。

开发分支另有“准备只读视觉预览”：先保存视觉目标并在专用画布按 F9 恢复，再点击按钮并在约 3 秒内切回画布；也可在倒计时内取消。该功能会截取所选窗口画面并交给配置的视觉模型，模型可能是远程服务；它不会发送键鼠输入。结果只展示有限的动作摘要，不能直接确认执行，也不代表之后画面未变化。关窗、离开设置、急停、连接或目标变化会撤销尚未发送的预览；请求发送后可能继续处理，不会自动重试。真实窗口和视觉模型仍待验收。

开发分支还提供独立的“准备可确认的视觉建议”，供上述专用画布验收。先保存视觉目标并恢复会话，点击准备后在约 3 秒内切回画布；准备阶段只截图和分析，不发送键鼠，画面可能发送给远程视觉模型。回到工作室，完整核对窗口标题、程序路径、进程身份和建议动作；文字动作可展开逐字符码点。建议自截图起最多保留 120 秒，超时需重新准备。确认实际执行时，点击“准备执行此建议”，在可取消的倒计时内切回目标窗口。确认会再次截图并核对画面、目标、许可和预算；动态画面变化可能导致拒绝。检查与系统输入并非原子操作，画面仍可能在两者之间变化。每次准备和确认都消耗截图预算，实际输入另消耗动作预算。

关闭、离页、急停或连接变化会撤销尚未发送的请求；已提交的操作可能仍在处理，不会自动重发。若结果未知，保留操作编号，查询状态并核对目标；需要结束跟踪时，先确认原服务已停止并核对目标。建议和状态仅保留在当前服务会话内，服务重启后无法查询原操作。每次服务最多登记 4096 项准备及确认操作，满后需核对未完成操作再重启服务。该模式的真实窗口、动态画面与键鼠仍未验收。

模型只返回一个受限 JSON 动作建议。服务拥有截图、绑定、预算、许可与协调器；模型不直接获得系统调用或进程启动接口。画面过期、窗口变化、聊天开始、暂停或停止后，旧建议与迟到画面都不得执行。每次仅执行一步，不自动循环或重试。

## 暂停、未知结果与数据

- 窗口关闭、进程身份改变、前台切换、DPI 或几何变化会拒绝当前操作。几何变化先更新待确认状态，再由你核对恢复，不自动沿用旧坐标。
- 开始聊天或语音交互会撤销原生动作代次；对话和播放结束后仍需手动恢复。
- 请求超时表示结果未知。先查看状态和画布，再决定下一步；相同操作 ID 不重放，部分输入失败不自动补发。
- 仅释放适配器自己成功按下的输入，不替用户抬起按键。捕获工作进程受本应用自己的 Job 管理，超时只结束自有进程，没有桌面全屏捕获后备路径。
- 原生审计位于配置审计文件旁的 `*.native.jsonl`，输入文本只记录长度。参考音频、记忆、配置和运行日志不进入默认诊断导出；窗口列表与目标也不进入诊断报告。

自动测试使用假系统调用与无窗口的捕获进程夹具。真实窗口、混合 DPI、真实键鼠、音频设备和私人旧库副本由用户按[整体验收流程](MANUAL_TEST_PLAN.md)执行，不能用自动测试替代。
