# Windows 便携版

完整解压 `AIex-Windows-x64-0.7.1-alpha.1.zip`，双击文件夹内的 **`AIex.exe`**。无需 Rust、Python 或 VTube Studio；请放在有写入权限的普通文件夹中。

## 第一次打开

- **先体验外形**：离线进入外形工作室，默认查看内置 OC“一号人物”，可切换人物、半身近景与全身立绘，也可导入自己的图片。无需账号或模型。
- **连接模型并开始对话**：进入连接设置，选择已有的模型服务，填写信息，保留自动启动服务并保存。
- 已配置的本地模型可以直接选择 **开始对话**；需要修改时选择 **连接设置**。

预览底部可以直接开始对话或返回首页，外形与配色会沿用到聊天。主窗口顶部提供聊天、角色与外形、场景组合、记忆、设置与诊断；输入区支持 Enter 换行、Ctrl+Enter 或按钮发送。设置页可打开连接设置或返回首页，有未保存草稿时会先提示。

人物素材已包含在桌面 EXE 内，显示为浅色底圆角插画卡，不需要额外的素材目录。展开“外形与自定义图片”，在“内置立绘”中选择“01 · 一号人物”或“02 · 初始伙伴”；一号人物可选“半身近景”或“全身立绘”。舞台点缀不会改变服装，人物选择和构图不会修改人格或记忆；自己的透明 PNG 外形仍可导入。

选择一号人物后，向下展开“OC 素材册”，可查看正式立绘、表情参考与四张静态动作。这里记住你上次查看的素材，但不会把动作应用到人物舞台。六格表情板是完整参考图，不是动画帧。一号人物支持局部眨眼、说话帧与半身近景的细微呼吸；不同情绪的动态表现可切换到初始伙伴体验。

保存的一号人物场景会记录人物选择与构图；旧 v1 内置场景恢复初始伙伴。载入完整场景仍需预览并确认其中的角色与外形。

连接设置提供“启用长期记忆”，保存后重启服务生效，关闭不会删除原记录。在“记忆”页展开“记下一件事”可保存笔记，也可查看、更正或确认遗忘单条记录。修改成功后清空当前上下文与聊天显示，聊天输入草稿保留。详细边界见[记忆工作台](MEMORY_WORKSPACE.md)。

真实对话需要云端服务的个人密钥，或正在运行且已安装模型的 Ollama / KoboldCpp。云端密钥不会保存到配置文件；未设置对应环境变量时，下次启动会再次进入设置。连通性检查只证明地址可达，实际鉴权和回答以服务结果为准。

语音、麦克风、VTS、OBS、直播和自动化默认关闭。先按[界面体验清单](MANUAL_TEST_PLAN.md)测试外形、文字和角色；以后再准备声音与转写服务。

## 程序与数据

```text
AIex-Windows-x64-0.7.1-alpha.1/
├── AIex.exe
├── ai-ex-service.exe
├── AIex.portable
├── 开始使用.txt
└── data/
    ├── ai-ex.local.toml
    ├── control.token       ← 首次保存设置后创建
    ├── memory.jsonl        ← 对话或保存笔记时按需创建
    └── logs/service.log    ← 启动后台服务后创建
```

保留整个文件夹，不要只复制桌面 EXE，也不要在压缩包内直接运行。程序根据自己的位置寻找配置，从快捷方式或其他工作目录启动也适用。默认控制端口为 17878。

配置和对话记忆位于 `data`，角色收藏、外形偏好和启动组合索引仍使用本机桌面设置。跨电脑请另外导出角色或场景包；移动后可能需要重新选择启动组合。此版本不保证整个桌面环境随文件夹迁移。

关闭聊天窗口或返回首页会停止它自己启动的服务；连接已经独立运行的服务时保留该服务。同一进程内可以复用刚填写的密钥；配置发生改变后不沿用旧密钥。缺少文件或配置不能解析时，会显示可复制信息的错误窗口，也可进入离线预览。

## 更新与反馈

关闭程序，把新版解压到新目录，保留旧目录作为备份。要沿用历史，可在两边程序都关闭后，将旧 `data` 中需要的配置与记忆迁移到新版；不要直接用分发默认配置覆盖个人设置。分享角色使用导出功能，避免分享整个 `data`。

反馈写明版本、操作步骤、预期和实际现象即可；必要时附 `data/logs/service.log` 中对应时段的错误。日志可能包含对话文本，分享前先检查。

## 维护者打包

在安装好 Rust 与 Windows 链接器的环境中执行 `tools/package_windows.ps1`。脚本只打包指定的桌面、服务和分发模板，验证 x64 可执行文件及版本，生成 ZIP 与 SHA256；已存在的目标会拒绝覆盖。

Windows GNU 构建需使用匹配的导入库和链接器。本版使用 LLVM lld 完成最终链接；仅将系统 DLL 目录加入库搜索路径不能保证程序能启动。更换工具链后，必须重新通过实际 EXE 检查。已经单独完成 release 构建时，可使用 `-SkipBuild` 打包。

`AIex.exe --check-install` 是无窗口的安装检查，校验标记、配置和旁置服务，不访问模型或设备。它不替代实际图形界面、网络服务或音频测试。
