# 声音与数字人表达

本文描述 0.7.1-alpha.1 的语句播放时间线与插画表现。

## 两条独立时间线

`ConversationState` 描述对话生成过程；`SpeechPlaybackSnapshot` 描述输出设备正在播放的语音。模型生成结束不等于扬声器已经播完，桌面表现层会优先使用实际播放状态。

Rust 原生播放器先解码 WAV 并计算约 40 毫秒窗口的 PCM 能量包络，再根据 Rodio 播放进度选择口型值。左右声道分别平方计算，避免反相立体声被误认为静音。低能量背景噪声不张嘴，口型值限制在 0–1000。

每句语音有独立 ID，并在入队时固定文字与情绪；重复的同一句话也有不同 ID。播放开始和结束通过 `speech_playback` 事件传递，中间的 `speech_progress` 仅包含语句 ID、进度和口型，避免每 40 毫秒重复传输整句文字。服务快照保留合并后的完整状态，客户端断线后可以重新读取。事件总线将序号分配、快照更新、历史追加和广播串行化，避免音频线程与对话线程产生乱序事件。

## 当前行为

- 内置插画的说话帧使用实际播放能量触发。仅生成文字、TTS 未启用或播放器未运行时，不产生模拟口型。
- 图片角色使用同一表现状态。桌面“正在说”显示当前播放的单句字幕和进度，长句可滚动；对话记录仍保留完整回答。
- 播放中的表情采用该句入队时的情绪，即使模型已生成完，也会保留到这一句播放结束。这里是表现情绪，尚不控制 GPT-SoVITS 的情绪音色。
- 外形工作室 `--preview` 继续使用明确标注的示意动画，方便离线设计。
- 对话已经生成完毕时，“打断”仍会取消剩余语音；重复打断可以安全执行。
- 新的有效输入会先取消上一轮剩余语音。`speech_cancelled` 清空播放状态并阻止迟到的开始/进度事件重新激活它；新一轮只接收自身的语音。
- 断线、事件缺口、停止和故障时，表现层抑制过时口型。
- 解码后的 PCM 有样本数量上限，异常音频不会无限扩大内存占用。格式错误和已取消音频不会发出播放开始事件。

## 插画与表现状态

`PresentationAnimator` 保留与渲染器无关的表现参数，负责眨眼、呼吸和有效口型采样。0.7 默认的一号人物保留 OC 主立绘，以独立校准的眼睛与嘴部贴层表现眨眼和说话；半身模式有细微呼吸，全身模式保持完整构图。初始伙伴继续使用 0.6 的局部表情帧。口型仍是离散画面，不是音素识别、骨骼动画或实时面部变形。自定义图片包继续按清单选择整张状态图，不修改用户图片。

一号人物暂不自动切换六表情参考或四张动作图；它们位于离线预览的素材册，只用于静态查看。情绪状态文字继续显示，初始伙伴保留对应情绪插画。浏览素材不会改变正在播放的语音、角色身份或实际外形。

停止条件优先于动画：静音、失同步、断线、打断、停止、故障、倾听以及减少动态效果不保留说话帧，旧音节不做拖尾。初始伙伴的惊讶使用闭嘴表情；减少动态效果还会停止呼吸与眨眼。

动画只保存当前外形的瞬时状态；页面长时间隐藏或时钟重置后不继续过时的过渡。长时间运行不再每 120 秒统一重置动画相位。它不会改变模型情绪、编造播放进度或新增主动行为。

## 启用与验证

从 0.3.0-alpha.1 起，打断覆盖模型初始化、记忆检索和语音入队等待。先取消语音，再清理可选外形；慢外形会产生诊断降级事件，不再阻断文字对话。适配器取消与外形调用使用 250 毫秒等待上限，这不等同于真实设备延迟保证。

完整回答开始写入记忆后，停止请求会取消语音并等待写入完成。此时已经完成的回答仍会保存。重复控制请求可以合并，等待对话超过运行时容量时返回明确错误。详见[版本说明与限制](releases/0.3.0-alpha.1.md)。

配置好 `[tts]` 和参考音频后，服务需要启用原生播放：

```powershell
cargo run -p ai-ex-service --features native-playback -- --config config/ai-ex.local.toml
```

确定性测试覆盖静音/有声区间、反相立体声、异常样本、播放结束、并发事件顺序，以及运行时 → 舞台 → 队列 → 播放上报 → 控制快照的语句身份和情绪传递。客户端测试覆盖事件回放、断线重同步、迟到消息抑制；4096 字长句的完整进度批次也检查消息大小。设备测试默认忽略，可显式运行；它只播放程序生成的静音，不采集麦克风：

```powershell
cargo test -p ai-ex-audio --all-features native_silent_playback_reports_progress_completion_and_interruption -- --ignored --nocapture
```

表现层确定性检查包括状态切换、不同刷新率、静音与停止条件、长时间运行，插画检查包括资源解码、状态选择和离屏绘制。当前版本的通过范围见[版本说明](releases/0.7.1-alpha.1.md)；这些检查不证明真实窗口观感或扬声器延迟，仍需按[验收流程](MANUAL_TEST_PLAN.md)体验。

当前是振幅驱动，不是音素/口形识别；设备缓冲与控制轮询仍会引入延迟。原生外形与桌面字幕已有语句级同步，默认插画消费同一播放状态。VTS 仍使用原有舞台口型命令，OBS 字幕仍按生成时的舞台动作调度；两者接入播放时间线和词级字幕继续留待后续。桌面和服务应一起更新，旧客户端不识别新增的进度与取消事件。
