## BGE 实测组合

## 参考音色与默认声音实测

参考音色使用 `wavekat-tts =0.0.5`、`ort =2.0.0-rc.12`、独立 ORT 1.28.2 和固定 `wavekat/Qwen3-TTS-0.6B-Base-ONNX` / `177cd39e2ddab0d4d7ce5152a7abc2d382621158`。36 个必要文件共 3,843,480,557 字节均完成校验；相同数据文件通过已核对摘要的私有硬链接复用。

Windows CPU release 探针完整加载六个模型并退出成功，加载 26.802 秒，采样峰值工作集 4,606,644,224 字节。另一独立进程用 7.867 秒的 Kokoro 合成参考音频生成「你好，我在这里。」：加载 24.291 秒、合成 21.179 秒、进程总计 46.889 秒，退出 0；输出为 24 kHz 单声道、44,160 样本、1.84 秒。RMS 为 0.071385，峰值为 0.416536，输出 SHA256 为 `30ece21879054fa694380dd621f0b9c6d486d264f1c3fafe639d74b8d2c7df1e`。原始记录位于 `target/m0-qwen-20261029/clone-result.json`。

该结果证明了参考音频、对应文本、六模型加载和生成路径实际执行。声音相似程度和听感尚未人工验收；目前也不代表服务已接入该后端。冷加载时限需依据实测设置，并在后台准备，不能占用控制请求的同步等待时间。

默认声音使用固定 Kokoro v1.1 的中文女声 `zf_079`，对应同版 `sid=46`；映射依据[同版官方示例](https://k2-fsa.github.io/sherpa/onnx/tts/all/Chinese-English/kokoro-multi-lang-v1_1.html)，不能跨版本复用裸序号。已生成 24 kHz、7.867 秒中文 WAV，RMS 为 0.068527。Whisper small INT8 读取该文件并实际完成中文识别，加载 17.403 秒、解码 3.157 秒，退出 0；原始识别包含添字和漏字，未宣称逐字准确。

Kokoro 和 Whisper 的受控取消探针在计算标记之后观察到 CPU 运算，自有进程分别在 62.075 ms 和 45.896 ms 内终止并回收。损坏 Whisper 模型导致原生 C++ 异常，进程退出码为 `-529697949`，异常被限制在探针进程内；不能把它解释为后端会返回普通 Rust 错误。九个用例的结果与运行文件清单在 `target/m0-native-backends-20261026/sherpa-final-evidence-20261029.json`。

Qwen 取消用例在合成调用开始后观察 500 ms，CPU 时间增加 765.625 ms，再发出终止请求；进程在 303 ms 内结束，退出 `-1`，没有生成目标 WAV。损坏首个 ONNX 文件返回 Protobuf 错误，12.211 秒后退出 `2`。结果与固定输入摘要在 `target/m0-qwen-20261029/evidence-20261029.json`。这些记录验证自有进程终止，不替代服务接入后的代次、队列和真实播放时钟验收。

Qwen 的原始输出为 Extensible Float32 WAV，Sherpa 当前文件读取器要求标准 PCM16。文件探针转换后，Whisper 实际识别为「你好,我在这里。」；转换输出摘要为 `efade52e719a48db2f8cfd5770394758a96ddb81153f2406d25f0fa0090275c7`。`ai-ex-inference::encode_mono_pcm16_wav` 已提供标准单声道 PCM16 编码，测试使用 `hound` 实际生成/读取 Extensible Float32 并验证转换结果；真实工作进程仍须在回复音频前接入此合同。

## 本地对话的失败门槛

固定 Ollama `v0.40.11` 与 Qwen3 4B GGUF 已在独立目录验证 CPU 私有服务、模型摘要和进程回收，未连接用户已有 Ollama。CPU 程序文件来自固定官方资产的受限条目提取，各条目完成大小/CRC、本地 SHA 与签名核对；**1,586,356,606 字节完整程序包的官方 SHA 尚未验证**，该 CPU 子集不是正式分发输入。

本次非思考预设未通过：`think:false`、固定派生模板和 `raw` 提示三种受限请求均输出推理内容，并在长度限制处结束。原始提示的真实换行与回复已核对，不能将该结果视为已验证的正常非思考回答。LLM 计算中的取消仍为 `not_run`。固定输入、请求/回复和 `M0Gate=failed` 记录见 `target/m0-ollama-20261029/evidence-20261029.json`、`nothink-result.json`、`raw-result.json` 及对应回复文件。
