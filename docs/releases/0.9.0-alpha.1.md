# 0.9.0-alpha.1：本地伙伴准备与原生推理

**状态：待发布。** 本页记录相对已发布 0.8.0-alpha.1 的用户可见变化。程序包、SHA256、固定模型目录及公开下载复核尚待发布流程完成；目前公开下载仍是 0.8。

## 本版变化

- 首页增加“准备本地伙伴”，在应用内创建独立设置、确认组件大小与许可、下载或离线导入模型，再进入本地聊天。
- 接入应用管理的 Ollama / Qwen3 4B 非思考对话、Sherpa Whisper small INT8 识别、Kokoro 默认中文声音、Qwen3-TTS Base 参考音色，以及 BGE 中文记忆嵌入。CPU 是本版基础路线。
- 声音向导支持清晰 WAV 与匹配文本导入、独立试听/停止、按人物身份保存声音。导入保存私人规范化副本，不修改原录音；不要求兼容旧 GPT-SoVITS 训练权重或生成完全相同的声音。
- 组件准备在后台执行，状态与取消结果可查询；摘要、文件大小和运行依赖全部满足才标记就绪。缺模型或加载失败保留其他可用能力、人物与控制界面。
- 试听复用实际播放队列和事件，不生成聊天轮次；打断、换轮和停止会使旧结果失效。停止确认后，迟到的旧试听请求不能重新启动或打断新聊天。原生计算无法协作停止时回收对应自有工作进程。

一号 OC、半身/全身、素材册、自定义图片、人物/场景组合、角色记忆工作台与外部模型连接继续保留；VTube Studio 和 OBS 仍是可选扩展。真实 Windows 捕获与键鼠仍未接入，合成模板回放继续使用 dry-run。

## 从哪里开始

完整解压程序，双击 `AIex.exe`，选择“准备本地伙伴”。创建设置后，先准备运行组件和对话模型，再按需要准备声音与识别。已准备文件可在后续离线使用；第一次下载和冷加载需要额外等待。

麦克风和播放默认关闭。保存播放开关不会自动试听，必须另点“播放试听”；后续对话从下一句话起读取声音设置。麦克风开关重新进入对话后生效。逐项操作和反馈格式见[整体验收流程](../MANUAL_TEST_PLAN.md)。

## 配置与数据

原生入口使用独立 `native-bootstrap.toml` 和 `native-v1.toml`，不静默覆盖原有个人连接配置。原生设置保存需匹配 revision，原字节先备份。便携版仍在程序目录的 `data` 保存数据；组件、私人声音、临时作业分开存放。模型可以先导入，运行包未齐时保留已校验文件，补齐依赖后无需重复下载。

人物/场景分享默认排除凭据、私人记忆、参考录音及对应原文。更换模型或预处理产生新的向量空间，旧向量不混查；重建保持显式操作。回退程序前保留数据副本，旧版本使用更新前的备份，不用 Git 恢复私人数据。

记忆写入保留原有两秒富化预算：冷加载或嵌入不可用时仍先持久保存文本并降级检索。需要补齐向量时，关闭使用同一数据的服务、备份后显式执行原生索引重建；具体入口见[工具说明](../../tools/README.md)。

## 待验收与后续

本机真实 CPU 的服务文字/记忆链路及开发运行包的中文目录文件语音链路已通过。正式对应源码、运行组件、最终目录与便携包仍待生成及校验，GitHub 发布尚未完成。真实扬声器、麦克风、听感/音色相似程度、完整离线桌面重启、GPU 包和未安装 Python 的干净 Windows 环境标记为 `not_run`，由相应流程实际执行后更新。

本版不退役仓库中的 125 个旧 Python 源码文件；新官方本地模型运行链使用 Rust 程序与无 Python 依赖的原生组件。0.10 的原生动作、旧记忆完整迁移及 1.0 的源码/工程零 Python 门禁仍未完成。完整范围见[分阶段迁移路线](../NATIVE_MIGRATION.md)。

正式运行包需携带对应源码及许可材料，固定输入的生成顺序见[原生发行工具](../../xtask/NATIVE_DISTRIBUTION.md)。不将待发布资产写成可用链接。
