# 0.8.0-alpha.1 · 记忆与合成回放工作室

本版扩展长期记忆的检索、来源核对与显式维护，并把合成模板回放接到服务和桌面。原有一号人物、人物选择、外形与场景流程继续沿用。

## 相对 0.7.1 的变化

- 可选语义召回保存带明确模型空间的向量，支持按当前角色显式重建；默认混合检索继续可用，也可选择旧核心的 L2 候选与评分策略。
- 记忆工作台新增实体线索、关联来源和媒体/标签筛选。更正或遗忘后，对应记录的向量与来源线索同步更新；实体候选保留证据与不同说法，供用户核对。
- 新增旧 JSON/gzip 备份、向量与元数据、多模态快照的显式迁移，以及 Chroma v2 只读导出和离线导入。媒体维护先预览，确认应用时将受影响原记录写入新归档，再替换当前角色的数据。
- 桌面设置页可开始、暂停、恢复和停止合成模板回放，服务持有会话和实际进度。回放使用清单图片和 dry-run 动作端口，坐标、预算、动作回执及审计沿用同一条受控链路。
- 排队对话、转写与语音合成/播放参与回放占用仲裁。聊天暂停在默认 30 秒静默且明确空闲后才可自动恢复；手动保持暂停可撤销自动恢复权，停止和急停有各自明确的终态。
- 可显式启用慢速视觉观察，只为同一目标建议搜索区域。宿主核对会话、代次、时效与几何后应用；慢观察没有直接输入、换目标或恢复会话的权限。
- 模板搜索可在原工作预算内分片并核验全局结果。预算内未完成时显示“搜索未完成”，保留费用与进度，不把暂定位置作为动作目标，也不自动增加预算或重试。
- 启动参数归到独立 `launch` 模块，界面、服务回放宿主和记忆存储的职责入口统一记入[项目目录](../PROJECT_LAYOUT.md)与[架构说明](../ARCHITECTURE.md)。

使用细节见[记忆工作台](../MEMORY_WORKSPACE.md)、[模板回放](../TEMPLATE_GAME.md)、[Chroma 桥接](../CHROMA_BRIDGE.md)与[Rust 迁移记录](../RUST_ONLY_MIGRATION.md)。

便携包同时提供 `ai-ex-migrate.exe`，无需安装 Rust 即可运行显式迁移。迁移仍通过命令参数操作输入副本和全新输出文件，桌面没有新增 GUI 数据导入入口；参数见[工具索引](../../tools/README.md)。

## 更新与兼容

完整解压新版便携包到新目录，桌面与服务一起更新，保留旧目录作为备份。旧服务不支持新的回放控制命令。配置与记忆的迁移方式见[便携版说明](../PORTABLE_WINDOWS.md)；不要用分发默认配置覆盖个人设置。

角色、图片外形和场景沿用现有包格式与稳定人物 ID；旧 Rust JSONL 仍可读取。旧备份导入、向量重建和媒体维护都需要显式执行，不在普通启动时扫描或迁移用户数据库。目标导入文件和维护归档必须是新文件；同一记忆库只允许一个写入方，锁冲突会明确拒绝。

向量必须具有一致的模型空间与维度，不能只凭维度相同混用不同模型。Chroma 快照保留实体集合的原始归档，但当前导入只转换主记忆，不恢复旧实体图。媒体描述和结构化特征不包含原始图片、音频附件，也不代表已自动理解这些媒体。

场景和角色分享继续排除私人记忆与本机凭据。跨电脑需要重新提供模型连接和本机资源；当前版本不保证整个桌面环境随文件夹迁移。

## 体验顺序

1. 完整解压后双击 `AIex.exe`，先检查原有离线人物、构图和场景恢复。
2. 连接自己的对话模型，在独立测试配置中启用长期记忆，保存一条确认笔记，查看实体来源，再尝试更正、遗忘和媒体筛选。
3. 按[模板回放说明](../TEMPLATE_GAME.md)准备合成图片与清单，连接桌面和服务，在设置页开始回放，核对暂停、恢复、停止及“搜索未完成”提示。
4. 准备好对应的嵌入模型、声音服务或视觉模型后，再检查可选语义召回、语音暂停和慢观察；未准备的项目记录为“未测”。

完整步骤与反馈方式见[整体验收流程](../MANUAL_TEST_PLAN.md)。

## 当前限制

合成回放没有接入真实 Windows 屏幕捕获和键鼠输入，慢观察也不执行任意 click、keypress 或 drag。固定工作预算下，困难纹理和未命中画面仍可能无法完成全局认证；合成基准不能证明真实游戏帧率。

实体线索来自本地规则与记录来源，不是外部事实核验。真实历史库、固定原生 Chroma 临时库、真实模型效果、音频设备、前台窗口操作与跨机器体验仍需各自验收。旧 Python 实现和尚未完成的核心迁移合同继续保留；本版不代表整个 Rust 迁移或数字人演进路线已经完成。
