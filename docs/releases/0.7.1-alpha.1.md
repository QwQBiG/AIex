# 0.7.1-alpha.1 · 架构与维护整理

这是基于 0.7 的维护更新，整理共享界面模块、强化依赖检查，并统一源码与历史资料的维护入口。默认 OC、人物选择、场景、对话和记忆的使用流程保持一致。

## 相对 0.7 的变化

- 欢迎、设置、预览、聊天和记忆页面直接使用独立的共享样式模块；页面之间不再通过聊天应用取得主题。离屏绘制和输入辅助集中在仅用于测试的模块。
- 架构检查同时核对包名、清单路径与依赖方向，拒绝未登记的本地包、同名不同路径和将内部包替换为注册表依赖的情况；检查器回归与故意违规探针加入 CI。
- 通用协议包沿用工作区的 Rust lint 设置，检查范围与其他核心包一致。
- 新增[项目目录](../PROJECT_LAYOUT.md)，修正源码、测试与工具目录索引，明确当前 Rust 主线、旧 Python 参考、资源和本机数据的归属，移除不适用的命令与验收承诺。

本版不改动人物素材、存储键、人物 ID、场景版本或控制协议格式。0.7 引入的 OC、素材册与场景 v2 说明继续见[0.7 版本记录](0.7.0-alpha.1.md)。旧源码和用户数据仍保留，目录整理不等于旧数据已经迁移。

## 更新与验收

将新版便携包解压到新目录，保留原目录作为备份，桌面与服务一起更新。配置和记忆的迁移方式见[便携版说明](../PORTABLE_WINDOWS.md)，不要用分发默认配置覆盖个人设置。

先按[整体验收流程](../MANUAL_TEST_PLAN.md)检查离线外形、宽窄窗口下的固定操作区、连接设置与返回首页，再连接自己的模型核对对话、角色和记忆。维护更新沿用 0.7 的功能边界；真实模型、声音设备和跨机器体验仍需整机验收。
