# 0.10.0-alpha.1 · 原生窗口操作与记忆迁移

本版延续 0.9 的本地对话、声音与人物，补齐 Windows 原生单步、来源记忆迁移和可控陪伴设置。使用前关闭旧程序，将新版完整解压到新目录，保留旧目录与私人数据备份。

## 用户可见变化

- 真实窗口通过独立 `StartNative` 入口绑定进程身份和几何代次；截图、点击、按键、文字、拖动、滚动、等待及无动作经过服务协调器、全局许可和持久审计。手动单步可在没有视觉模型时使用，视觉模型仅建议受限动作。
- 合成 `StartTemplate` 保留图片回放与 dry-run 合同。窗口、前台或几何变化、聊天、暂停和急停撤销原生操作；结果未知与部分执行失败不自动重试，只释放自有输入。
- 便携包新增平台助手和用户自行打开的测试画布入口。快捷键默认关闭，应用后报告实际注册状态；服务重启需重新应用，急停保持到重启。
- 悬浮字幕跟随真实播放；可调位置、样式与鼠标穿透。主动输出受空闲、冷却、免打扰和静音时段控制，不伪造用户消息或写入用户记忆。
- 独立运行设置支持显式应用与重载；VTS 可发现当前模型的热键。诊断导出使用允许字段清单，排除原始日志、对话、凭据、窗口信息和私人音频文本。
- 版本化 JSONL 保留实体候选、本人/第三方/未知主体及来源贡献。更正或遗忘撤销对应贡献，多来源与未解析关联继续保留；旧平铺文件首写前备份，也可先预览再输出新文件。
- Chroma 由固定原生服务打开工作副本后导出，保留原始快照、向量空间与未解析实体关联。工具拒绝覆盖现有输出，不改写原始 SQLite/HNSW 格式。
