AIex 数字伙伴 · 0.7.1-alpha.1 Windows 便携版

1. 将压缩包完整解压到可写入的文件夹，再双击 AIex.exe。
2. 点击“先体验外形”，默认查看内置 OC“一号人物”，无需导入素材。

展开“外形与自定义图片”，在“内置立绘”中切换“01 · 一号人物”和“02 · 初始伙伴”。
一号人物提供“半身近景”和“全身立绘”；初始伙伴保留原有情绪表现。
人物显示为浅色底圆角插画卡，“舞台点缀”不改变服装，“减少动态效果”会停止动画。
也可选择“自选图片”导入自己的图片，或选择“隐藏外形”。

选择一号人物后，向下展开“OC 素材册”，查看立绘、六格表情参考和四张静态动作。
素材册只供查看，不会把动作应用到舞台；切换人物或构图不会修改人格、记忆。
保存的一号人物场景会记住人物和构图，旧 v1 内置场景仍恢复初始伙伴。

需要真实对话时，直接点击预览底部的“开始对话”，外形会沿用到聊天中。
在设置里选择已有的模型服务，填写地址、模型名和所需密钥，保留自动启动服务后保存。
本地模型需事先运行 Ollama 或 KoboldCpp；云端模型需你自己的 API 密钥。
云端密钥不写入配置文件；没有设置对应环境变量时，每次打开会提示填写。

主窗口顶部可以切换聊天、角色与外形、场景组合、记忆、设置与诊断。
Enter 换行，Ctrl+Enter 或“发送”提交；中文输入法确认候选不会直接发送。
设置页可以返回首页或打开连接设置，不用退出重开程序。

在连接设置勾选“启用长期记忆”，保存后重启服务生效；关闭不会删除原记录。
打开“记忆”页，展开“记下一件事”保存笔记；也可查找、更正或确认遗忘单条记录。
修改成功会清空当前上下文与聊天显示，聊天输入草稿保留。
写入结果不确定时先刷新核对，避免重复保存；自动记录不等于已确认事实。
同样信息若存在于其他记录或角色设定，需要分别处理。
重开后能继续使用已保存记忆，但不会恢复完整旧聊天显示。

无需安装 Rust、Python 或 VTube Studio。模型、声音资源不包含在程序包里。
语音与麦克风默认关闭，先测试外形与文字对话即可。
不要只复制 AIex.exe：同目录的服务程序、AIex.portable 和 data 文件夹需要一起保留。
配置和对话记忆在 data 中；后台服务日志在 data/logs/service.log。
角色收藏和部分外形偏好仍保存在本机桌面设置中，跨电脑请先导出角色或场景包。
更新时先关闭程序，将新版本解压到新文件夹；保留旧 data，不要直接覆盖你的数据。

测试时记录：版本、点击了什么、看到什么、原本期望什么。
遇到启动错误可以在错误窗口复制信息；无需先学习命令行。
